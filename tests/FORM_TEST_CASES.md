# Тест-кейсы попапа подключения организации

## Автоматически при сборке архива

Команда `python3 scripts/publish-b2b-landing.py` сначала запускает `scripts/test-form.py`. Если проверка не проходит, ZIP-архив не создаётся.

Проверяются:

- наличие модального попапа;
- форма только с обязательным номером телефона;
- открытие попапа по кнопкам подключения;
- валидация пустого и неполного номера;
- отправка в AmoCRM только номера телефона;
- защита от повторной отправки;
- аналитика показа попапа и переход к регистрации.

## Браузерная матрица

| Сценарий | Действия | Ожидаемый результат |
| --- | --- | --- |
| Открытие | Нажать «Подключить организацию» в первом экране | Открывается попап с одним полем номера телефона |
| Закрытие | Нажать крестик, затем открыть снова | Попап закрывается и открывается с пустым полем |
| Escape | Открыть попап и нажать Escape | Попап закрывается, фокус возвращается на кнопку |
| Пустая форма | Нажать «Подключить организацию» в попапе | Появляется просьба указать номер, перехода нет |
| Неполный телефон | Ввести несколько цифр и отправить | Появляется ошибка корректности номера |
| Корректный телефон | Ввести полный номер и отправить | Кнопка блокируется, затем открывается регистрация организации |
| Двойной клик | Быстро нажать кнопку отправки дважды | Обрабатывается одна отправка |
